# Crypto Map：一张图看懂加密资产产业

一张可以点的产业地图，回答三个问题：

1. **谁在参与？** 38 类参与者，每一类都有典型代表机构、赚钱方式和风险点。
2. **他们在哪一层？** 从上到下七层：用户 → 入口 → 中心化中介（CeFi）→ 链上协议（DeFi）→ 资产 → 公链与基础设施 → 监管与外围。横轴从左边的法币世界一直到右边的链上世界。
3. **钱和币怎么流、记在谁的账上？** 八条资金流一步步动画回放，每一步都写进“账本”卡片，标明是银行账本、交易所内部数据库、证券登记，还是区块链。

## 章节

| 章节 | 内容 |
|---|---|
| **分层**：七层结构 | 逐层讲这一层做什么，高亮它和其他层的连接 |
| **参与者**：谁是谁 | 点地图上任意参与者：代表机构、怎么赚钱、风险在哪、出现在哪些资金流里 |
| **资金流**：钱怎么流 | 散户买币、DeFi 一圈、华尔街买币（ETF）、稳定币的一生、一个新币、挖矿出币、跨境汇款、黑客与追踪 |
| **稳定币**：链上的美元 | 铸造、储备、赎回和冻结；GENIUS 法案、香港《稳定币条例》、MiCA |
| **发币**：新币从哪来 | 风投 → 做市商 → 上所 → 解锁；矿工出块 → 场外卖币 |
| **风险**：出事的地方 | Mt. Gox、Terra、3AC/Celsius、FTX、Ronin、USDC × SVB，以及 Bybit 被盗全过程回放 |

## 运行

纯静态网站，无需构建。任意静态服务器即可（ES modules 需要 `http://`）：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

可以直接部署到 GitHub Pages、Netlify 等。唯一的外部请求是 Google Fonts（可选）。

## 代码结构

- **`js/data.js`**：全部内容。`LAYERS`（七层）、`NODES`（参与者：位置 `x` 从 0 链下到 1 链上、代表、赚钱方式、风险）、`FLOWS`（每一步的起点、终点、移动的是什么、记在哪本账上、账本记录和解释）。改内容只需要改这个文件。
- **`js/map.js`**：地图。按层排布参与者（放不下时自动折成两行），在下层画布画连线，在上层画布画移动的资金和金额标签。
- **`js/chapters.js`**：每章的高亮、控件、数字和正文。
- **`js/app.js`**：路由（`#flows/stable`、`#players/cex`）、播放器、账本卡片和悬浮卡片。
- **`tools/shot.mjs`**：用 Playwright 截图（`node tools/shot.mjs 1440 900 home flows/etf@6000`），`og.png` 就是这样生成的。

## 说明

- 账本记录里的地址、区块号和金额是示意，不是真实交易。
- 市场数据（规模、利润、持仓）只给数量级，截至 2025 年前后，会过时。
- 仅用于学习产业结构，不构成投资建议。
